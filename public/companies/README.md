# Brand assets

These local SVGs are used for company and repository identity surfaces. They were downloaded from public brand repositories so the deployed UI does not depend on runtime third-party image requests.

- Google, Apple, Meta, Netflix, Uber, and GitHub: [Simple Icons](https://github.com/simple-icons/simple-icons)
- Amazon and Microsoft: [Vector Logo Zone](https://www.vectorlogo.zone/)
- Flipkart: [Wikimedia Commons](https://commons.wikimedia.org/wiki/Special:FilePath/Flipkart_logo_(2026).svg)

All trademarks belong to their respective owners.
